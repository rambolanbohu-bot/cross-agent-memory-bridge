# Cross-Agent Memory Bridge v1.0.0

Cross-Agent Memory Bridge is a public, MIT-licensed Agent Skill for local-first personal AI memory management. Copyright (c) 2026 Rambo.

The project provides explicit change and export approval, privacy checks, manual portable snapshots and version rollback. It uses the Python standard library and does not require a paid API or server; selected AI services may charge separately.

Evidence covers Windows local behavior and the GitHub Actions matrix for Windows/Ubuntu with Python 3.11 and 3.12. Linux/macOS complete installation, Claude native execution, Gemini native execution, Muse integration and Windows junction behavior remain untested or skipped. Exported snapshots do not provide automatic all-AI synchronization, and automated privacy checks do not replace manual review.

Review the code, license and package hashes before installation. Release assets and distribution channels are maintained separately from the source documentation.
