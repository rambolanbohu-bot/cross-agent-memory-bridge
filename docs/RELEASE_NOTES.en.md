# v1.0.0 — Public repository, GitHub Release pending

Cross-Agent Memory Bridge is available in a public repository under the MIT License: Copyright (c) 2026 Rambo. The GitHub Release v1.0.0 has not been published.

The project provides local-first Agent Skill profiles with explicit change/export approval, privacy checks, manual portable snapshots and version rollback. It uses the Python standard library and does not require a paid API or server; selected AI services may charge separately.

Evidence currently covers Windows local behavior and the GitHub Actions matrix for Windows/Ubuntu with Python 3.11 and 3.12. Linux/macOS complete installation, Claude native execution, Gemini native execution, Muse integration and Windows junction behavior remain untested or skipped. There is no automatic all-AI synchronization.

Install only after reviewing the code, license and package hashes. Preserve prior reviewed packages for rollback. Publication of a GitHub Release, tag creation and third-party submissions are separate owner actions.
