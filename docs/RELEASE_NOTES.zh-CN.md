# Cross-Agent Memory Bridge v1.0.0

Cross-Agent Memory Bridge 是一个公开、采用 MIT License 的本地优先个人 AI 档案 Agent Skill。Copyright (c) 2026 Rambo。

项目提供明确的变更与导出审批、隐私检查、手工跨 AI 快照与版本回滚。核心使用 Python 标准库，不要求付费 API 或服务器；用户自选AI服务可能另外收费。

现有证据覆盖 Windows 本地行为，以及GitHub Actions的Windows/Ubuntu、Python 3.11/3.12矩阵。Linux/macOS完整安装、Claude原生执行、Gemini原生执行、Muse集成和Windows junction行为仍未验证或保持跳过。导出快照不提供所有AI之间的自动同步，自动隐私检查不能代替人工审核。

安装前请审查源码、许可证和包哈希。发布资产和分发渠道与源码文档分开维护。
