# Release checklist / 发布门禁
- [x] Core unchanged; staged differences and allowlist reviewed locally.
- [x] Owner confirmed MIT, individual public attribution Rambo, year 2026; full LICENSE and metadata synchronized.
- [ ] Owner reviews refreshed hashes, privacy/license reports and separately approves any publication action.
- [ ] Confirm maintainer/CODEOWNERS and private reporting channel.
- [ ] Confirm name/brand rights; no trademark ownership claim.
- [ ] Keep junction SKIPPED, platforms NOT_TESTED, remote CI NOT_RUN until real evidence exists.
- [ ] Review final source/install ZIP extraction, hashes, privacy exceptions and exact file allowlist.
- [ ] Separate authorization for new empty public repo and independent Git init/staging/commit/push.
- [ ] Configure protection and run real CI; require maintainer approval.
- [ ] Separate approval for v1.0.0 tag/Release and any SkillsMP submission.

Nothing here authorizes remote actions. Never fork private history or change private visibility. Synthetic approval is not publication approval. 禁止自动公开；最终包变化必须重算哈希。
