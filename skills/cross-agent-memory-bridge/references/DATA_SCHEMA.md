# Schema 1.0 / 数据结构
profile.json has exactly schema_version ("1.0"), positive integer version, updated_at (ISO UTC), records and audit. Each record has exactly id, text, source, created_at, verified_at, status, tags, visibility, sensitive and version. Dates are ISO dates. Stable IDs: lowercase ASCII letters/digits/hyphens, at most 64 characters. Source: user/document/agent-proposal/synthetic. Status: confirmed/pending/superseded. Visibility: private/shareable. confirmed requires verified_at. New records start at version 1; corrections increment by one. Duplicate IDs, normalized fact texts, operations, JSON keys and unknown fields are rejected.
Only confirmed + shareable + sensitive=false records enter read/export. Pending count is separate. Revoke marks superseded. Conflicts require new proposal and approval, no silent merging. Markdown is not parsed as facts. Export hash binds schema, source version/hash, target and selected records; generated_at is metadata outside that hash. SHA256 detects changes, not authorship.
结构唯一来源是 profile.json；待确认不是事实，重复和冲突拒绝。哈希不是签名。
