# Privacy / 隐私与威胁
Findings contain category, relative location and line, never the matched value. Normalize NFKC/remove zero-width format characters. UTF-8/BOM and UTF-16 are supported; binary/unknown encoding, files over 1 MiB and trees over 2000 entries are blocked. Detect common token, credential, JWT, private-key, long bank/ID-like number, contact, sensitive keyword and filename patterns. Split secrets, Unicode lookalikes and contextual meanings may evade regex. A false negative is not consent.
Reject links/Windows reparse points including internal junctions, and parent traversal. Report hidden directories without walking them. Exclude .git metadata; --staged explicitly reads index blobs/sizes, not just the worktree. ZIP inspection extracts nothing and rejects traversal, drive/absolute paths, symlinks and excessive sizes. No ZIP import exists.
Threat model: accidental leaks/cooperating agents, not hostile same-user processes. Portable stdlib path checks cannot eliminate all adversarial filesystem substitution races. Protect backups and directories. No encryption is provided. Source scans may flag security docs/test code semantically; exceptions require review.
人工核对每条事实含义、第三方信息、用途、接收者、必要性和外部备份去向。正则不是 DLP 保证，须人工复核。检测报告不包含秘密原文。
